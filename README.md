- **The website**, [frontenddesignbasics.vercel.app](https://frontenddesignbasics.vercel.app), is the live guide. Every tool, example and principle runs in the browser.
- **This repo** is the same guide in Markdown ([`guide/`](guide/)), plus [`toolkit/toolkit.json`](toolkit/toolkit.json): which tool to use for which job, in a form your AI agent can read at the start of a project.

## [05] Use it with your agent

The guide ships as an agent skill. At the start of every project it reads the toolkit and the rules,
proposes what fits your brief, and asks you to choose before anything is designed.

```bash
npx skills add br9704/frontenddesignbasics
```

The whole guide is also served as [`/llms.txt`](https://frontenddesignbasics.vercel.app/llms.txt), and
[`AGENTS.md`](AGENTS.md) has the rules for agents working on this repo.

## [06] Run it locally

```bash
git clone https://github.com/br9704/frontenddesignbasics && cd frontenddesignbasics
pnpm install
pnpm dev              # http://localhost:3000
pnpm build            # production build
pnpm gen              # regenerate README sections, GALLERY.md and AGENTS.md from the data
pnpm posters          # re-render the 30 experience posters (needs the site on :3000)
pnpm journey:gif      # re-record the README journey GIF (needs the site on :3000)
pnpm verify           # motion, reduced-motion and 390px checks (needs the site on :3000)
pnpm export:md        # export every docs page to GitHub markdown in guide/
```

The design contract is in [`DESIGN.md`](DESIGN.md): tokens, type, ASCII, 3D and motion rules.
