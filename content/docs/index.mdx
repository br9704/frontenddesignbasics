## Where to start

1. **Starting a project?** Read [Start a project with the toolkit](/docs/how-to/start-a-project).
2. **Building one effect?** Find it in [How-tos](/docs/how-to).
3. **Reviewing work?** Run down [the twelve rules](/docs/rules).
4. **Looking for ideas?** Read a [case study](/docs/cases), then browse [/sites](/sites).

## Use it with an agent

The whole guide is published as [`/llms.txt`](/llms.txt), and the tools live in one
[`toolkit.json`](https://github.com/br9704/frontenddesignbasics/blob/main/toolkit/toolkit.json).
Point your coding agent at the repo and ask *"what in here fits this brief?"*
