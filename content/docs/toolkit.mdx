## Status key

| Status | Meaning |
|---|---|
| **live** | Installed and connected. Use it now. |
| **needs-key** | Wired up. Needs an API key or sign-in before first use. |
| **dormant** | Wired up. Needs a paid plan before it does anything. |
| **on-demand** | A local server. Start it, then launch the agent in its folder. |
| **library** | No MCP. Install the package in the project that needs it. |
| **tool** | A web or desktop app, used by hand. |

## Picking from it

Don't use everything. A typical site needs **one motion library, at most one 3D or shader approach,
one component source, and the review skills**. More than that and the site starts to look like its
dependencies.
