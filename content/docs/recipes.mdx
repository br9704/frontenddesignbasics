## The hero

The first screen has one job: say what this is, in the most characteristic form the subject allows.
This site's hero is the anatomy to copy:

| Layer | This site | Principle |
|---|---|---|
| Texture | Ink shader on a paper plate | A background with a subject, kept behind text |
| Headline | Serif at `clamp(3rem, 9vw, 8.5rem)`, tight leading | One huge thing per view |
| Support | One sentence, 44ch max | Measure keeps it readable |
| Actions | One solid, one outline button | One primary action |
| Eyebrow | Mono, uppercase, tracked | A small detail that sets the tone |

```tsx
<section className="relative min-h-[82svh] overflow-hidden rounded-xl">
  <InkField />                           {/* texture, clear zone behind text */}
  <div className="relative flex min-h-[82svh] flex-col justify-between p-10">
    <p className="font-mono text-xs uppercase tracking-[0.2em]">A field guide</p>
    <div>
      <h1 className="font-display text-[clamp(3rem,9vw,8.5rem)] leading-[0.9]">…</h1>
      <p className="mt-6 max-w-[44ch]">…</p>
    </div>
  </div>
</section>
```

## The scroll story

Pin a section, scrub a timeline to scroll, release. That's the core of every "award" scroll site.

```ts
const mm = gsap.matchMedia();
mm.add('(prefers-reduced-motion: no-preference)', () => {
  const tl = gsap.timeline({
    scrollTrigger: { trigger: '.story', start: 'top top', end: '+=2000', scrub: 1, pin: true },
  });
  tl.from('.story h2', { yPercent: 100, opacity: 0 })
    .to('.story .image', { scale: 1.15, filter: 'saturate(1.2)' }, '<')
    .from('.story .caption', { opacity: 0, y: 20 });
});
```

For whole pages built this way, the **scroll-world** and **scrollcraft** skills plan the structure and one
signature move before any code. Pair with Lenis for inertia.

## The footer

The footer is the last impression and the most-skipped design task. A complete one has:

- the name and one line of what it is
- the three to five links people actually look for (contact, source, legal)
- a real sign-off, with personality allowed
- enough space above it to feel like an ending, not a cut-off

## Why it works

Recipes are principles under load. Each one is just type scale, one accent, space and motion rules
applied to a common job, which is why they can be reused without looking reused.
