## Decisions that made it feel right

- **Every colour is an exact game value.** The palette comes straight from the game's `globals.lua` colour table: red `#fe5f55` for MULT, blue `#009dff` for CHIPS. Tailwind's default palette is wiped (`--color-*: initial`) so no off-brand colour can sneak in.
- **Buttons are built the game's way.** Stepped corners from a 20-point `clip-path`, no border-radius, and a face that drops 6px onto a hard shadow when pressed.
- **One unit rules the layout.** The spacing unit is 96px, a twentieth of a 1920×1080 stage.
- **The backgrounds are the game's shaders.** Its own swirl shaders were ported onto a single WebGL canvas, keeping the original constants.
- **Music as layers.** Five synced layers of one song, crossfaded by state over 1.5 s, with the master at −18 dB.
- **Progress in the game's language.** Slides advance as blinds and antes, not page numbers.
- **Tuned for the room.** On a projector the in-game background looked frozen, so it runs at 2.5× speed with contrast raised to 1.35.

## Stack

Vite · React 19 · Motion · OGL for the shaders · Tailwind v4 · Playwright for visual checks.

## What to take from it

1. When a brief says "make it feel like X", **get X's real material** and read the values.
2. **Wipe the defaults** so the only colours available are the right ones.
3. **Test in the real setting.** The projector changed the shader speed.
