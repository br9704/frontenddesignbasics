## The problem

Desktop-OS portfolios are memorable, and almost all of them are invisible to search: they're a
single-page app or an iframe, so nothing inside is crawlable. The brief was to keep the concept and
lose the penalty.

## The decision that made it work: the parity rule

> Every window type whose content exists at a real route renders the **same** server component in
> both contexts. No window type gets two content implementations.

The "OS" is a client shell (`DesktopShell`) that draws window chrome **around** real Next.js routes.
Every one of the **28** case studies lives at `/projects/[slug]` as server-rendered HTML. The window
is only a frame. The consequences are small, and they are all design decisions:

- Long-form text sits in a `<details>` element styled as Notepad, not in a spawned window, so the prose
  stays in the server HTML.
- Closing a routed window calls `router.push(parentRoute)`, never `router.back()`, which would throw
  direct visitors off the site.
- Focusing a window that has no route changes no URL, so history isn't spammed.

## Research as a design tool

The aesthetic holds up because it was researched rather than remembered. A 132-line spec with a
confidence key (verified, era-standard, tuned by eye) fixed the numbers: **18px** title bars,
**16×14px** caption buttons, a **28px** taskbar and **75×23px** push buttons. Outline dragging was
chosen because full-window drag arrived with Microsoft Plus!, not with 95. There's no pointing-hand
cursor because 95 RTM didn't have one.

## Constraint as a system

- **One sanctioned colour.** The palette is anchored to real High Contrast Black, plus exactly one
  non-grey colour: `#FBAF5D`, the orange of *"It's now safe to turn off your computer"*.
- **Nothing Microsoft-owned ships.** Fonts are MIT or OFL recreations. Icons and cursors are hand-drawn
  SVG pixel rects. The four UI sounds are resynthesised rather than sampled.
- **Boot as the only 3D.** A 1.0 MB Draco-compressed retro computer (three.js + R3F) draws a BIOS POST
  on its screen, dollies in, and crossfades to the DOM in 250ms or less. It runs only on `/`; deep
  links skip it.

## Stack

Next.js 16 · React Three Fiber, drei and postprocessing · three.js · zustand for the window manager ·
Supabase for the guestbook and hit counter.

## What to take from it

1. A strong concept is only craft if the fundamentals (SEO, routing, accessibility) survive it.
2. Research the real thing. The details you'd guess are the ones people notice.
3. Pick one constraint and let it generate the rest of the system.
