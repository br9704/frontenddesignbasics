## First, do you need WebGL?

Most "make it 3D" briefs are satisfied by depth, not by a scene. Try CSS first:

```tsx
<div style={{ perspective: 900 }}>
  <div
    onPointerMove={onMove}
    style={{ transform: `rotateX(${x}deg) rotateY(${y}deg)`, transformStyle: 'preserve-3d' }}
  >
    <p style={{ transform: 'translateZ(60px)' }}>Depth without a scene</p>
```

Reach for real 3D when the object **is** the story: a product people want to turn over, a world to
move through, data that lives in space.

| Brief | Reach for | Why |
|---|---|---|
| React site, custom scene | **three.js + React Three Fiber + drei** | Largest ecosystem; drei covers loaders, controls, environments |
| SvelteKit site | **Threlte** | The same ideas, declarative in Svelte |
| A designed moment, fast | **Spline** | Model and animate visually, export an embed or code |
| Game-like, edited by a team | **PlayCanvas** | Engine + collaborative editor (+ editor MCP) |
| Ready 3D UI pieces | **ThreeUI** | Orbs, globes, cards via `npx @designcodeio/threeui-cli add` |
| An object from a photo | **img2threejs** skill | Rebuilds it procedurally in code, animation-ready |
| Scroll-driven 3D world | **scroll-world** skill | Brand → scrollable 3D landing page |

## A minimal R3F scene

```tsx
'use client';
import { Canvas } from '@react-three/fiber';
import { Environment, Float, OrbitControls } from '@react-three/drei';

export function Scene() {
  return (
    <Canvas dpr={[1, 1.75]} camera={{ position: [0, 0, 4], fov: 40 }} frameloop="demand">
      <Float speed={1.4} rotationIntensity={0.6}>
        <mesh>
          <torusKnotGeometry args={[0.8, 0.28, 220, 32]} />
          <meshPhysicalMaterial color="#ff5c1f" roughness={0.25} clearcoat={1} />
        </mesh>
      </Float>
      <Environment preset="studio" />
      <OrbitControls enableZoom={false} />
    </Canvas>
  );
}
```

## Performance rules

- **MUST** cap device pixel ratio (`dpr={[1, 1.75]}`). 3× renders 2.25 times the pixels of 2× for almost no visible gain.
- **MUST** compress models: Draco or Meshopt geometry, KTX2 textures. BR95's retro computer ships at **1.0 MB**.
- **MUST** pause when off screen (`frameloop="demand"` or an IntersectionObserver) and when the tab is hidden.
- **MUST** give reduced-motion users a still pose, and everyone a fast poster image while the scene loads.
- **SHOULD** keep draw calls low: instance repeated meshes, merge static geometry.
- **SHOULD** skip heavy 3D entirely on deep links, where people came for content (BR95 only boots its 3D on `/`).

## Why it works

3D is persuasive because it's physical: light, material and parallax tell the brain "this is real". That
same weight makes it expensive, so spend it only where it carries the story.
